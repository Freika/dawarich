Proposed tasks below belong to the pending milestone 4 plan, not an approved implementation decision.

## Risks and open decisions for the controller

1. **Upload ownership/lifecycle:** external PUT completion is not a durable import claim; cancel-upload removes a LiveView entry but current receipt contains only blob/user. Plan explicit pending lifecycle, bounded expiry and purge tombstone, race-safe claim versus cancel. Never purge an attached archive/export. Sources: `D/storage/upload_receipts.ex:4-25`, `D/storage/native_purge.ex:6-74`, `W/account_live/edit.ex:85-99`.
2. **Budgets/compression:** Rails ZIP preparation buffers the whole original; native checksum already chunks. Decide max entries/aggregate bytes/preparation concurrency/TTL/timeout; preserve effective legacy-trial 11 MiB and source detection by default. Sources: `app/javascript/services/zip_file.js:3-13`, `D/imports/upload_admission.ex:126-145`.
3. **Batch semantics:** existing Phoenix create is atomic; Rails iterates valid references and later cleans failed batch. Preserve current port atomic semantics unless controller asks for parity adjustment; assess duplicate names and same-token replay explicitly (`D/imports/upload_create.ex:16-27`, `app/controllers/imports_controller.rb:64-92`, `D/imports/upload_records.ex:92-117`).
4. **Notification outbox deletion:** row-ID events cannot identify a deleted row/owner after deletion; owner-level invalidation must survive transaction/restart, including read-all/delete-all, without making every socket poll. Existing relay polling is infrastructure, distinct from forbidden navbar polling (`D/cable/turbo_events.ex:8-23`, `D/cable/events_relay.ex:9-10`).
5. **Per-delivery admission:** family hook checks events but not updates; notification info hook refreshes cached actor. New hooks/context methods must check params/info/async as applicable, clear confidential state first on refusal, and never redirect indefinitely to the same refused destination (`W/family_gate.ex:28-56`, `W/notification_session.ex:52-108`).
6. **Public native transport:** HTTP unlock cannot become a socket event. Recommend HTTP controller renders a separate native read-only LiveView with bounded signed admission, verified before subscribing and on each delivery; discard raw phrase/cookies/capabilities before storing/logging. Final transport/grant contract needs controller approval and adversarial tests (`W/shared_link_page.ex:32-80`, `W/shared_link_cookie.ex:1`).
7. **Map/host scope:** full family/shared pages cannot be called Hotwire-free while native hooks transitively look up Stimulus. M4 needs focused family/public rendering hooks; main map/studio and rich editor stay M6/M5. Recommend data-heavy sharing entrypoints link to a native sharing manager until those hosts migrate (`family_page.js:1-6`, `W/components/sharing_parts.ex:30`, `W/components/share_hub/body.html.heex:77`).
8. **Job cancel/retry:** distinguish cancelling an unfinished upload, cancelling a durable queued/running job, retrying failed/stalled extraction and replaying a durable event. Do not promise a generic worker cancellation the worker cannot fence. Default existing delete/removal semantics, introduce explicit fenced cancel only after controller decision (`T/dawarich/imports/destroy_test.exs`, `T/dawarich/imports/lease_test.exs`).
9. **Retirement breadth:** shared POST must go only after replacing its import consumers and verifying no hidden host still uses it. Retained public/JSON/API routes lose hand-back gates but keep real security and independent wire contracts. Secrets in crash “Last message” are covered by 3b redaction lessons; new presign/phrase handlers need forced-failure tests.
10. **Acceptance:** sparse query counts do not demonstrate upload capacity, event ordering under load or browser teardown. Use deterministic synchronization, synthetic inputs and reduced VM schedulers, never host-wide stress. No release/lifecycle edits.
