# Visual and map parity divergences

These are intentional differences between native Phoenix pages and Rails 1.16.0, as required by ADR-0025. Every difference the parity bench reports must be fixed or listed here with its reason. An unlisted difference is a defect.

Categories:
- `contract`: a native contract forces it;
- `wiring`: markup that only connects LiveView or hooks;
- `post-1.16.0`: a change from Rails dev after 1.16.0, kept on purpose;
- `resilience`: copying Rails would break the text-resilience rule.

### D3 family shell and row focus follow-up

The family map now renders D1's standard application layout inside its existing admission guard, including the navbar, application container, flash, onboarding and footer. The application body and viewport replace fullscreen map settings for this page only. Forty-nine shell sidecars recorded by the existing Rails family recorder cover seven admitted states in seven locales; shared `layout_parity_test.exs` retains every other page's chrome assertions. The former open shell and row-focus rows are resolved. Coordinates remain confined to admitted client reads; row clicks send no receipt or socket event. Refresh, clear, offline, lease expiry, departure and destruction retire focus data/listeners along with the map. Controller browser acceptance remains separate.
