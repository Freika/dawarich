# Admin and settings browser request parity

Native instance settings admit the rendered submit button's `button` field only on instance writes. Other form field allowlists remain unchanged. Turbo submits both a per-form body CSRF token and a global header CSRF token; like Rails, admission requires at least one valid session/action token and still rejects foreign origins, duplicate headers, and envelopes with no valid token. POST forms with `_method=patch` preserve the rate-setting 303 redirect and section query.

The test-email link submits POST with `_method=post` and a browser HTML Accept header. Native admission retains session identity, admin role, origin, bounded form transport and action CSRF validation. Invalid standalone envelopes return a native 422 instead of contacting the retained Rails upstream. Valid self-hosted requests enqueue the existing mail worker and return the source HTML redirect; Cloud retains its existing refusal.

Rails constrains `/admin/settings` to administrators at route recognition. Native refusal returns 404 for signed-in non-admins on this path. `/settings/users` preserves the source referrer redirect; `/sidekiq` preserves its root redirect and error flash.

`G44AdminBrowserTest` exercises these envelopes through Endpoint, plus the visits toggle's overridden POST and the map transportation allowlist/reclassification flow. The reclassification write characterizes existing behavior at the implementation head. Visits toggle admission reuses the raw body saved by the native integration rate limiter; rereading a consumed network body would otherwise reject the valid overridden POST, a behavior hidden by the reusable Plug test adapter. The standalone transportation progress API reads the existing native recalculation status manager, including completion and start time, so browser polling sees native worker progress instead of an idle legacy cache entry. Synthetic settings and private database/Redis connections come from the test environment. Each named regression has a production mutation checked by the implementation report.
