# A12f-2J routing and transport integration

Source base: `f73a1f0e29c2cf03353aeabacc7241fb63875648`, Rails 1.15.3 absorbed.
Rails API declarations remain in `config/routes.rb:312–464`. The transport
oracle is `ApiController`, ActionDispatch and Rack CORS; package contracts are
in `a12f2-b.md`, `a12f2-c.md`, `a12f2-e.md` and `a12f2-i.md`.

Ruling 15 prioritizes activation of the merged B/C/E/I handlers. D/F/G/H remain
unmerged and their coexistence seams remain. This is route integration, not
Ruby-free release acceptance. Per-key rollback retains original request bytes;
accepted native work drains without transfer to Sidekiq.

Verification and remaining work are recorded in the controller execution report.

B activation selects the closure actions for locations, private thumbnails and
place CRUD, and declares photos, suggestions, nearby/search and Immich enrichment.
Collection declarations precede place members. Existing slice names are retained.
The real Endpoint test passes without upstream requests; deleting suggestions
makes its authentication assertion receive the fake Rails response instead.

C activation invokes its spatial route macro, selects terminal digest reads,
and declares MCP GET/POST/DELETE. Tiles require the literal `.mvt` suffix and
use fixed MVT negotiation. Hexagon index/bounds accept validated shared-stat
grants; fog and other spatial reads require API authentication. MCP preserves
raw request bodies and delegates bearer-only admission to its own transport.

E activation declares imports, public pending intake and point mutations, with
collection/position paths preceding members. All four ingestion routes use
native tuple actions. Pending mode/origin refusals and import reads now reach
the merged handlers instead of the CORS limiter deferral.

I activation declares public signed blob proxy and all representation variants,
and admits direct uploads through Rails session decoding and the merged guest
CSRF handler. Storage bodies bypass the common API parser. Invalid signatures
and missing CSRF terminate natively; `active_storage` remains the rollback key.

CORS is the first request policy before AuthGate/Strangler. Source preflight
responses are empty 200s even for denied origins/methods/paths; only pending
POST/OPTIONS receives allow headers. Actual pending responses always vary on
Origin and allowed origins keep headers on errors. Credentials are never enabled.

All existing API slices and Cable admit explicit Cloud mode while retaining
coexistence slice switches. API GET routes and public signed storage support
HEAD; Cable HEAD refuses HTTP upgrade using the original method. Browser slice
HEAD behavior remains with its page owner.

Owned API bodies now decode Rack-shaped query/forms with scalar last-wins,
nested maps/arrays, valueless parameters and source query limits. JSON retains
last duplicate values and deep-munge; multipart/chunked intake supplies Plug.Upload
without applying the former 2 MiB replay ceiling. Rare encoding/JSON/parameter
shapes remain explicit parity follow-up under ruling 15.

API suffixes normalize for routing while retaining the original target. Native
format selection respects suffix precedence and weighted Accept lists. POST
method override uses form/multipart `_method` before the header and ignores
query/JSON override parameters, matching installed Rack 3.2.7. Coexistence pins
are checked before parsing and hand-back restores the original method.

Native API authentication retains explicit blank-key precedence over Bearer.
Rails browser session decoding supports client-marker cookies while API actor
identity remains API-key based. Cloud pending-payment responses issue the
native checkout token. The limiter consumes already-parsed native parameters;
legacy browser/auth seams keep their existing conservative parser.

Unknown closed API paths and routing-constraint misses return native 404s.
Digest years retain the source four-digit constraint and tile routes retain
literal MVT suffixes. API ID guards that were stricter than Rails are removed.
Closed API exceptions terminate at a native renderer; browser exceptions stay
with their existing owner. Unmerged mutation/auth/mobile paths remain deferred.

AuthGate checks existing top-level hand-back keys before dispatching any
enabled handler. A calibrated native credential form proves the `users` pin
wins before native cookies/effects. F/G/H additions and their Cloud flow
activation remain their accepted-handoff dependency.

Owned API failures now terminate in Body.replay rather than retrying a request against Rails. A real native point ingestion with an injected after-commit render failure retains one SQL write and its original sent500, even if replay is requested afterward. This proves the SQL boundary; the corresponding subscription/mail/token/remote matrices require the unmerged owner packages and remain open.

POST method override checks the original declared slice before reading its body.
A disabled ingest route keeps even malformed JSON/query bytes for Rails when a
GET on the same path remains enabled. API and storage rollback probes verify
original POST, suffix/encoded query, opaque cookie, header and exact form bytes,
with no cookie/outbox writes and a native neighboring photo route. Cross-slice
multipart overrides and the complete F/G/H auth matrix still need follow-up.
