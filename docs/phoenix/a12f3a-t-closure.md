## Implemented journey

Trip index/new/edit render in self-hosted, explicit Cloud and unset-default modes. Trip show retains future itinerary and studio rendering. Missing scoped trips terminate with 404. In standalone mode domain refusals terminate with an error instead of requiring an absent Rails web process; configured coexistence upstreams keep their existing admission behavior.

Show calculation admits the existing `command:trips.calculate` Oban producer in Cloud mode. Future imported trips bypass calculation. Name-only updates do not enqueue another calculation. Invalid Turbo create preserves the Rails MissingTemplate status of 500 without writing a trip. Existing cooldown, concurrency, owner fencing, completion and rollback tests remain in place.

`Trips.Photos.load(user, started_at, ended_at, zone)` consumes the existing `Photos.Index.fetch/3` result/cache contract. It groups provider timestamps in the user timezone, preserves source ordering, chooses up to twelve previews from the dominant orientation and builds source browser links. The show and day components render the thumbnail links; the existing Stimulus photo toggle remains the map consumer.

`Trips.RichContent` retains the strict legacy `TripDescription` parser and adds a separate bounded ActionText path. The captured description corpus renders byte-identically, including HTML repairs, source sanitizer behavior, Trix external image attachments, entities and void tags. Create/update retain signed ActiveStorage blob attachments, canonical Trix markup and shared embed associations. Native identification reads a bounded storage chunk before save and detects supported PDF/image signatures before trusting declarations. The disabled source image processor uses NullAnalyzer inline; audio/video analysis remains in Oban. Nonempty description replacement and dependent trip deletion call the shared storage-first purge helper. Empty/nil description updates retain embeds as Rails does. Deletion scopes rich-text fields to `description` and attachments to `embeds`; unrecognized legacy fields or attachment names and their blob references remain as Rails leaves them. Failed storage removal retains blob, preview and variant rows for retry, and blobs attached elsewhere remain intact. Gallery layout and preview bounds match the source. Trix editor serialization preserves Ruby integer bases/whitespace, source metadata types, nullable dimensions and explicit HTML-content values without inventing rendered preview content. Editor and display rendering remain separate: replacing a display-failing description succeeds, and the display sanitizer keeps its source behavior. Notes preserve leading newlines, local-noon upserts, actor/trip scope and plain-text HTML escaping. Trip date-only, named-month, offset, overflowing-calendar and fractional-second inputs reuse the existing native date parser and preserve source casting. Note dates also accept commercial weeks and ordinal days. Exports use the existing locale approximations and the trip's local start date; a body format overrides a query format, and preparation exceptions produce the source 422 redirect.

## Native producer contracts

`Trips.ShowCalculation.run(repo, user, id, context)` calls `Trips.WebCommands.calculate!` with actor-scoped trip, units and source clock. It persists a UUID/version-1 `trips.calculate` command, aggregate/dedupe identity and scheduled time under the existing owner lock. No native path publishes a `trips.calculate` reverse effect. Accepted-work completion remains with the existing calculation worker and shared owner APIs.

Trip export calls the existing PointExports producer under `command:exports.points`, using the scoped actor, format, original UTC bounds and source filename. The exporter owns worker completion and blob attachment. No exporter codecs or storage primitives changed here.
