# Native stage-2 source test retargets

Milestone 6 was merged onto the stage-1 integration without rewriting either history. This ledger records inherited named cases whose native successor has a different name. Unchanged names retain their original case. The source fixture corpora, numeric values, policy checks, effect snapshots and retained protocol byte assertions remain in their owning files.

Retired map frames and unsupported old UI writes now test local retirement alongside the canonical source data. Activated Trip forms and month hosts now test their native admission. Rails importmap, signed DOM stream and Stimulus markup assertions have native entry, typed producer and scoped browser-reader successors. Old browser-provided flash events are refused; permitted producer feedback has separate behavior coverage.

Some source cases map jointly to two successors. Names containing `#{@name}` refer to the unchanged named fixture corpus loop. The native shell/achievement successors live in `native_pages_hotwire_free_test.exs` and `native_shell_events_test.exs`; all other successors stay in the source file shown.
