# Provider authentication closure (A12f-2G)

Source baseline: 6ed35e332, Rails 1.15.3 absorbed. Characterization: 2026-10-06.
NE-5 follows source policy, including optional mobile Google nonce.
This package requires the mandatory authentication review before integration.

## Source contracts

- Devise provider registration: config/initializers/devise.rb:274–312.
  Cloud configures GitHub and Google; self-hosted configures OIDC.
  Unset SELF_HOSTED means self-hosted.
- Provider account resolution: app/services/auth/find_or_create_oauth_user.rb.
  Existing provider/uid wins, including missing-email callbacks. Deleted
  accounts are refused. Verified email collisions require explicit linkage;
  web callbacks do not automatically send mail. Registration-disabled OIDC
  still permits returning identities.
- Web callback completion: app/controllers/users/omniauth_callbacks_controller.rb.
  OAuth callbacks sign in directly, including OTP-enabled users. Account-link
  confirmation instead requires a subsequent two-factor sign-in.
- Link JWT and Redis consumed-marker behavior:
  app/services/auth/{issue_account_link_token,verify_account_link_token}.rb.
  Mark before save, retain the marker on a subsequent save failure.
- Redirect ordering: app/controllers/application_controller.rb:95.
  Pending import claim, invitation, payment, mobile, stored local destination.

## Characterization

The existing auth activation recorder also writes the package-specific
test/fixtures/auth/a12f2g/providers.json. Existing activation output is unchanged.
It records account creation, missing-email fallback, returning identities,
registration denial, deletion, and boolean/string email verification collisions.
Source gems: omniauth-github 2.0.1, omniauth-google-oauth2 1.2.3,
omniauth_openid_connect 0.8.0, openid_connect 2.3.1.

J owns route activation, AuthGate, strangler and slice configuration. No final
Endpoint ownership is claimed by this package's direct-handler tests.
